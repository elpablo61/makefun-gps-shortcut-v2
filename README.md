The GPS's one-line excuse for sending the driver down the wrong road — smug,
defensive, and blaming the map. Entry for the make.fun bounty
[The GPS Swears It Was a Shortcut](https://make.fun/bounty/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9).

## The line

> The map told me to turn left at the red barn. The red barn is a wedding venue now. Congratulations, you are the plus-one.

## Run

```sh
node main.ts
```

Writes the single line (121 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`).
